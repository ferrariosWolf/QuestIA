# QuestTools

Ferramentas locais para desenvolvimento e sideload legítimo no Meta Quest.

- `check-quest.ps1`: reinicia ADB e verifica o headset.
- `install-apk.ps1 -ApkPath .\APK\arquivo.apk`: instala/atualiza um APK.
- `quest-info.ps1`: mostra modelo, versão do sistema e Beat Saber.

Use somente APKs próprios, de desenvolvimento ou obtidos de fontes autorizadas.

# DrumSaber

Protótipo standalone para Meta Quest 3, milestone v0.1.

## Abrir

Abra esta pasta no Unity `6000.0.66f2` ou posterior compatível. A cena `Assets/Scenes/DrumSaber.unity` é criada automaticamente pelo bootstrap em runtime; para um primeiro teste no Editor, use Play Mode.

## Controles de teste no Editor

`A` simula baqueta esquerda, `D` simula baqueta direita e `Space` inicia/reinicia a música. No Quest, o bootstrap aceita controladores XR quando OpenXR/XR Interaction Toolkit estiverem presentes.

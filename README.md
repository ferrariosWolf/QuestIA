# Quest AI Assistant

Fundação do Quest AI Assistant para Meta Quest 3, Unity 6, Android/Horizon OS e OpenXR.

## Estrutura

- `quest-app/`: aplicativo Unity XR.
- `backend/`: placeholder do backend seguro futuro.
- `docs/`: documentação técnica do projeto.
- `builds/`: APKs gerados localmente.

## Versão atual

`0.1.0` — aplicativo mínimo para validar a cadeia Unity → Android → Meta Quest 3.

Esta versão não contém OpenAI, voz, câmera, passthrough, memória, agentes ou integrações externas.
